# HW4
Задание №4 курса Data Science

Реализовать минимум 5 классификаторов, сравнить метрики между собой, выбрать лучший для датасета.
Использовать набор данных Human Activity Recognition Using Smartphones для классификации типов активности человека. Обучить модель и оценить ее при помощи метрик качества

В работе был использован открытый датасет Activity Recognition Using Smartphones
Авторы датасета представили 2 набора данных: тренировочный и тестовый. Из-за большого размера тренировочный оказалось невозможно разместить на ресурсе. Датасеты для работы доступны здесь: https://www.kaggle.com/datasets/uciml/human-activity-recognition-with-smartphones

Набор данных содержит информацию о 561 параметре, снятом с датчиков гироскопа и акселерометра смартфона, когда использующий смартфон человек находился в разных положениях

Наилучшие результаты показал метод опорных векторов (SVM), показавший точность предсказаний по всем параметрам оценки качества классификатора 95,6%
